## Unified Keybindings (Tmux & Zellij)
All shortcuts use `Ctrl+Shift` as the modifier for universal compatibility across devices and environments. Resize and layout bindings use `Alt` (tmux-only, no zellij equivalent in shared set).

| Binding | Action (Tmux) | Action (Zellij) |
| --- | --- | --- |
| `Ctrl + Shift + p` | Display Command Palette | Display Command Palette |
| `Ctrl + Shift + Up` | Next Window | Next Tab |
| `Ctrl + Shift + Down` | Previous Window | Previous Tab |
| `Ctrl + Shift + m` | New Window | New Tab |
| `Ctrl + Shift + e` | Close Window | Close Tab |
| `Ctrl + Shift + w` | Kill Session | Close Session (Exit) |
| `Ctrl + Shift + Left` | Focus Left Pane | Focus Left Pane |
| `Ctrl + Shift + Right` | Focus Right Pane | Focus Right Pane |
| `Ctrl + Shift + 1` | Create Tiled Pane (Max 4) | Create Pane (Max 4) |
| `Ctrl + Shift + 2` | Close Pane | Close Pane |
| `Ctrl + Shift + r` | Reload Config | N/A |
| `Ctrl + Shift + ,` | New Session | New Session |
| `Ctrl + Shift + 0` | Cycle Sessions | Detach |
